Introduction to Quarto

  • Quarto is an open-source scientific and technical publishing system.
  • Create dynamic documents: Word, PDF, HTML, Slides.
  • Supports R, Python, Julia, and Observable.

Why Use Quarto?

  • Professional reports and reproducible research.

  • One document ➔ multiple formats.

  • Text + Code + Output seamlessly integrated.

x <- c(1,2,3,4,5)

Controlling Code Behavior

Chunk options:

  • echo: Show code?

  • eval: Run code?

  • warning: Show warnings?

  • error: Show errors?

execute:
  echo: true
  eval: true
  warning: false
  error: false

YAML Basics

Placed at top between --- lines.

Controls metadata and formatting.

Simple YAML:

---
title: "Sample Report"
author: "A Student"
format: docx
editor: visual
---

Common Metadata Fields

Field Purpose
title: Document title
author: Author(s)
date: Document date
format: Output format (docx, html, pdf)

Format Options

Simple:

format: docx

Multiple outputs:

format:
  html:
    toc: true
  pdf:
    toc: true
  docx:
    toc: true

Word-Specific Options

format:
  docx:
    toc: true
    toc-depth: 2
    number-sections: true
    reference-doc: custom.docx

  • toc: Table of contents

  • number-sections: Number headings

  • reference-doc: Custom Word template

Appearance Customization

theme: cosmo
mainfont: "Times New Roman"
fontsize: 12pt
geometry: margin=1in

Citations and Bibliography

bibliography: references.bib
csl: apa.csl
citeproc: true

  • bibliography: BibTeX file

  • csl: Citation Style Language file

Full YAML Example

---
title: "Research Report"
author: "A Student"
date: today
format:
  docx:
    toc: true
    number-sections: true
execute:
  echo: true
theme: cosmo
mainfont: "Georgia"
fontsize: 11pt
geometry: margin=1in
bibliography: refs.bib
csl: apa.csl
editor: visual
---

Important Notes

✅ YAML is space sensitive, not tab sensitive.

✅ Always double-check filenames.

✅ Indent properly inside YAML blocks.
